Magasins par onglet

Choisissez les magasins proposés dans chaque onglet. La liste vient d'Openbravo (organisations avec entrepôt) et se relit chaque nuit ou avec le bouton.
Les changements Ventes / Stocks s'appliquent aux données à la prochaine collecte (ventes : chaque heure ; stocks : chaque nuit). L'historique des ventes d'un nouveau magasin se reprend avec le traitement « Rattrapage de l'historique ».
